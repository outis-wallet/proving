GPU bridge demo

Prover threads (threaded wasm, rayon on Web Workers) call a synchronous GPU M31 product served by a GPU worker (wgpu on WebGPU) through the shared memory. Query (defaults): ?threads=8&phases=correctness,errors,latency,throughput&jobs=256&iters=200&sizes=64,128,256,512&reps=3; transfer sizes in MiB: upload_chunk_mib=16&upload_window_mib=64&readback_chunk_mib=16 (0: unbounded); kick_ms: empty submits while a job waits (default 2 on Firefox, else 0).
